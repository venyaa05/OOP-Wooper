# 🌌 Welcome

> *"Clean Code. Smart Design. Powerful OOP."*

The **Employee Management System** is a **menu-driven Command Line Interface (CLI)** application built entirely in **Python** to demonstrate the practical implementation of **Object-Oriented Programming (OOP)** concepts.

Instead of simply storing employee information, this project is designed to showcase how real-world software can be structured using reusable classes, inheritance, encapsulation, and polymorphism.

Whether you're a student learning Python or building your GitHub portfolio, this project demonstrates a strong foundation in software design principles.

# 📖 About the Project

Managing employee information is a common requirement in many organizations.

This project simulates a simple **Employee Management System** where users can perform essential operations such as adding, updating, deleting, and displaying employee records through an interactive console menu.

The project also introduces specialized employee types (**Manager** and **Developer**) to demonstrate inheritance and method overriding, making it a practical example of object-oriented programming in Python.

# 🧠 OBJECT-ORIENTED PROGRAMMING CONCEPTS

<img src="https://img.shields.io/badge/OOP-IMPLEMENTATION-blueviolet?style=for-the-badge"/>

</div>

| 🧠 Concept | 📖 Description |
|------------|---------------|
| 🏗️ Classes & Objects | Created reusable classes to organize employee information. |
| 🧬 Inheritance | `Manager` and `Developer` inherit properties from `Employee`. |
| 🔒 Encapsulation | Employee ID and Salary are private attributes with getters/setters. |
| 🎭 Polymorphism | `display()` behaves differently depending on the object type. |
| 🔄 Method Overriding | Child classes customize the inherited display method. |
| ⚙️ Constructor | `__init__()` initializes every object. |
| 🗑️ Destructor | `__del__()` notifies when an employee object is removed. |
| 📦 Class Variable | Tracks the total number of employee objects. |
